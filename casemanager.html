This is the main workspace for Case Managers, containing all essential information related to patient management and coordination.

Key Features:

Daily Tasks:

This table displays daily responsibilities and actions that need to be completed by the Case Manager. Click the "Details" button to open the To-Do interface, where you can add and track specific tasks related to each day.

Patients in Treatment:

View a list of patients currently undergoing treatment. To see more information about a specific patient, click the "Details" button.

New Patients Table:

This section displays new patient entries submitted via the consultation request form.

Click on a patient's name to view the initial details provided in the form.

Click "Details" to open the full patient profile.

Add Record / Case Manager Checklist:

Clicking the "Add Record" button opens the Case Manager Checklist, outlining the steps the Case Manager should follow for each case.

Doctors & Assigned Patients:

This table shows a list of doctors and the number of patients assigned to each.

Click on the number of assigned patients to view the list.

Click on a patient's name to access their full profile.

Appointments:

Use this section to schedule appointments by assigning specific dates and times for patient sessions with doctors.
